# Contributing

Thanks for your interest. This is currently a solo project.

- **Issues are welcome.** Use the bug or feature template.
- **Code contributions aren't accepted yet.** The project is licensed under [FSL-1.1-ALv2](LICENSE.md), and accepting outside code would first need a contributor license agreement, so that licensing stays in one hand ([ADR-003](docs/adr/003-repo-visibility-and-license.md)). Pull requests from outside contributors will be closed with a thank-you.
- **Security issues:** see [SECURITY.md](SECURITY.md). Never use a public issue.

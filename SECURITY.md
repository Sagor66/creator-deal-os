# Security policy

## Reporting a vulnerability

**Please don't open a public issue for security problems.**

Report privately through GitHub: go to this repository's **Security** tab and choose **Report a vulnerability**. Only the maintainer sees the report.

Please include:
- what you found and where (file, endpoint or URL)
- steps to reproduce, or a proof of concept
- the impact you expect (e.g. one workspace reading another's data)

You'll get an acknowledgement within 5 working days. Please give us reasonable time to fix the issue before disclosing it publicly.

## Scope

- This repository's code.
- Any deployment of Creator Deal OS run by the maintainer.

Out of scope: denial-of-service testing, social engineering, and testing against other users' accounts or data. Only use workspaces you created yourself.
